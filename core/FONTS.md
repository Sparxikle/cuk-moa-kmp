# App fonts

The app font **CUK Moa Sans** is a modified version of [Pretendard](https://github.com/orioncactus/pretendard) (© 2021 Kil Hyung-jin),
subset to only the characters the app needs. It is licensed under the SIL Open Font License 1.1. The original's Reserved
Font Name "Pretendard" may not be used for modified versions, so it was renamed. Full license: [PRETENDARD_OFL.txt](PRETENDARD_OFL.txt)

To rebuild: `python3 tools/fonts/subset_fonts.py <folder with the original Pretendard otf files>`
